# Проект: Тестирование интернет-магазина Intershop 🛒

**Роль:** QA Engineer (ручное тестирование)
**Задача:** Проверить функциональность, найти дефекты, оценить готовность к релизу.

## 🛠 Что делала:
* Составляла тест-кейсы и чек-листы.
* Оформляла баг-репорты в баг-трекере YouGile.
* Проводила тестирование требований и витрины товара.
* Выполняла дымовое тестирование новой функциональности.
* Проводила API-тестирование (Postman): проверка запросов, ответов и остатков.
* Тестировала безопасность (XSS, SQL-инъекции, IDOR).
* Выполняла повторное (ретест) и регрессионное тестирование.
* Анализировала ошибки в DevTools (Network, Console).
* Тестировала обновлённый сайт после релиза.

## 📊 Результаты:
* Написано и пройдено: **223 тест-кейса**.
* Найдено: **55 багов** (включая критичные в регистрации и расчёте стоимости заказа).
* Выявлены дополнительные дефекты в браузере Firefox (корзина, купоны, поле «Количество»).
* Составлен итоговый отчет с рекомендациями: продукт не рекомендован к выпуску до устранения Critical и Major-дефектов.

## 🧰 Инструменты:
Postman, Chrome DevTools, Figma, YouGile.

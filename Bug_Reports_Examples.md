# Примеры баг-репортов (Intershop)

Ниже представлены примеры оформления дефектов в баг-трекере YouGile.

---

### Баг 1: В корзине некорректно рассчитывается общая сумма заказа
* **ID:** ETA4-87
* **Приоритет:** Critical (Критический)
* **Окружение:** Google Chrome 150.0.7871.182, Firefox 153.0, macOS Tahoe 26.5.2.
* **Предусловие:** В корзину добавлены товары. Открыта страница корзины.

**Шаги воспроизведения:**
1. Перейти на сайт https://intershop4.skillbox.ru
2. Добавить товары в корзину.
3. Перейти на страницу корзины.
4. Сравнить итоговую сумму в блоке «Общая сводка» с суммой товаров.

**Фактический результат:** В блоке «Общая сводка» сумма заказов не совпадает с суммой товаров.

**Ожидаемый результат:** В блоке «Общая сводка» отображается корректная сумма, равная сумме всех товаров в корзине.

### Баг 2: Отображается кнопка «Заархивировать» вместо «Зарегистрироваться»
* **ID:** ETAS-3
* **Приоритет:** High (Высокий)
* **Окружение:** Google Chrome 147.0, macOS.

**Шаги воспроизведения:**
1. Перейти на сайт https://intershop2.skillbox.ru
2. Нажать кнопку «Войти» в правом верхнем углу.
3. Внизу формы «Мой аккаунт» нажать кнопку «Зарегистрироваться».
4. Под формой регистрации проверить текст кнопки.

**Фактический результат:** Под формой отображается кнопка «Заархивировать».

**Ожидаемый результат:** Под формой отображается кнопка «Зарегистрироваться».

### Баг 3: При применении валидного промокода в корзине применяется скидка 100% вместо 20%
* **ID:** ETA4-23
* **Приоритет:** Critical (Критический)
* **Окружение:** Google Chrome 148.0.7778.217, macOS. Пользователь авторизован.

**Шаги воспроизведения:**
1. Перейти на сайт https://intershop3.skillbox.ru/
2. Добавить любой товар в корзину.
3. Перейти на страницу «Корзина».
4. В поле «Введите код купона» ввести валидный промокод `GIVEMEHALYAVA`.
5. Нажать кнопку «Применить купон».

**Фактический результат:** Применяется скидка 100%. Сумма заказа становится 0,00₽.

**Ожидаемый результат:** Применяется скидка 20%. Сумма заказа пересчитывается корректно.

### Баг 4: Разрешён доступ к заказу другого пользователя через подбор ID в URL (IDOR-уязвимость)
* **ID:** ETA4-33
* **Приоритет:** Critical (Критический)
* **Окружение:** Google Chrome 147.0.7727.139, macOS Tahoe 26.3.1 (25D2128).

**Шаги воспроизведения:**
1. Авторизоваться под `user1`.
2. Оформить заказ.
3. Перейти в раздел «Мои заказы».
4. Зафиксировать ID заказа (например, `893091`).
5. Выйти из аккаунта `user1`.
6. Авторизоваться под `user2`.
7. Открыть URL: `/my-account/view-order/893091` (используя ID заказа `user1`).
8. Сравнить отображаемые данные заказа (номер, дата, статус, сумма, адрес) с данными заказа `user1`.

**Фактический результат:** Пользователь `user2` получает доступ к странице заказа пользователя `user1` по прямой ссылке. Отображаются данные чужого заказа (номер заказа, состав заказа, стоимость и другая информация).

**Ожидаемый результат:** Доступ к заказу другого пользователя запрещён. Данные чужого заказа не отображаются.

### Баг 4: Сервер принимает отрицательное значение в поле `stock_quantity` при PUT-запросе
* **ID:** ETAA-8
* **Приоритет:** Major (Значительный)
* **Окружение:** Postman (API), Google Chrome (UI).
* **Предусловие:** Товар с ID `887746` существует на складе.

**Шаги воспроизведения:**
1. Открыть Postman.
2. Выбрать метод **PUT**.
3. Ввести URL: `http://intershop3.skillbox.ru/api/products/887746`
4. Установить заголовок `Content-Type: application/json`.
5. В теле запроса (Body -> raw -> JSON) передать отрицательное значение: `{"stock_quantity": -7}`.
6. Отправить запрос.
7. Открыть карточку товара на сайте `https://intershop3.skillbox.ru` и сравнить остаток.

**Фактический результат:** Сервер возвращает статус `200 OK` и сохраняет отрицательное значение остатка (например, -5). На сайте отображается некорректный остаток.

**Ожидаемый результат:** Сервер возвращает статус `400 Bad Request` и сообщение об ошибке валидации. Остаток на складе не меняется.
